#								Libft-1337 School Project

#	Description :
Libft is the foundational project at 1337 Coding School. The objective is to recreate a set of standard C library functions from scratch, along with linked-list functions, and bundle them into a static library (libft.a) for use in future projects.

#	Instructions :
Clone the repository and compile the library using the Makefile:
```bash
# Compile Libft functions and produce libft.a
make

# Clean object files (.o)
make clean

# Clean object files (.o) and the compiled library (libft.a)
make fclean

# Rebuild the library from scratch
make re
```
